
  # Convert Figma to React App

  This is a code bundle for Convert Figma to React App. The original project is available at https://www.figma.com/design/02pTqLjD8sNkyQC9rq295s/Convert-Figma-to-React-App.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Frontend-only testing

  This project can run without the backend while the API is still being built.
  `Frontend/.env.local` enables mock responses with:

  ```bash
  VITE_USE_MOCKS=true
  ```

  To test against the real backend later, change it to `false` or remove the line.
