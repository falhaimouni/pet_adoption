Based on the current backend, the live API is centered on auth, users, pets, adoption requests/adoptions, medical records, and vaccinations. The database schema is broader than the implemented controllers: it already has tables for conversations/messages, notifications, suppliers/supplies, departments/employees, file uploads, OAuth, password reset tokens, and activity logs, but those do not currently have backend modules/controllers exposed.

Live modules from Backend/src/app.module.ts: AuthModule, UsersModule, PetsModule, MedicalModule, VaccinationsModule, AdoptionsModule.
